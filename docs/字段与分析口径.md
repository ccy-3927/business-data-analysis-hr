# 字段与分析口径

原始字段保持英文名称，中文只用于展示。原始数据为1470行35列。来源没有观察日期，以下“年”均为个人经历长度，不是观测年份。

| 原始字段 | 解释及分析方式 |
|---|---|
| Age | 年龄；原始记录保留，不进入本项目预测模型 |
| Attrition | 离职标签Yes/No；派生Exited=1/0；不是有明确期间的年度离职率 |
| BusinessTravel | 出差频率类别；独热编码 |
| DailyRate | 原始日费率字段；具体业务与币种说明不足，不输入模型 |
| Department | 部门；分类编码并派生中文部门 |
| DistanceFromHome | 居住距离原始数值；来源未明确距离单位，不擅自标公里 |
| Education | 教育等级：1大学以下、2学院、3本科、4硕士、5博士；模型中作为类别 |
| EducationField | 教育领域类别 |
| EmployeeCount | 全部为1的常量，不建模 |
| EmployeeNumber | 唯一员工编号，仅作审计键 |
| EnvironmentSatisfaction | 环境满意度：1低、2中、3高、4很高 |
| Gender | 性别；用于样本结构与误差诊断，不输入预测模型 |
| HourlyRate | 原始时费率字段，具体业务与币种说明不足，不输入模型 |
| JobInvolvement | 工作投入度：1低、2中、3高、4很高 |
| JobLevel | 职级；分类预测中独热编码；聚类中作有序数值，需承认等距假设 |
| JobRole | 岗位；ABC分类以此聚合 |
| JobSatisfaction | 工作满意度：1低、2中、3高、4很高 |
| MaritalStatus | 婚姻状态；原始记录保留，不输入模型 |
| MonthlyIncome | 月收入，币种未明确，展示为原始数值单位 |

| NumCompaniesWorked | 曾任职公司数量 |

| OverTime | 是否加班Yes/No；不是加班小时数 |

| StockOptionLevel | 股票期权等级；分类编码 |
| TotalWorkingYears | 总工作年数 |
| TrainingTimesLastYear | 原始字段定义为上一年培训次数；具体日历年份不明 |
| WorkLifeBalance | 工作生活平衡：1差、2好、3较好、4最好 |
| YearsAtCompany | 公司司龄，年 |
| YearsInCurrentRole | 现岗位年数 |
| YearsSinceLastPromotion | 距上次晋升年数 |
| YearsWithCurrManager | 与当前经理共事年数 |

## 派生字段

Exited为目标的明确二元映射；岗位、部门、加班是中文映射。司龄组按0—1、2—3、4—5、6—10、11年以上划分。Cluster与分群来自七维K-Means描述分析，群编号按群月收入均值排序固定，仅为可解释命名，不代表优劣。ABC来自岗位的离职案例累计贡献，固定于全样本。

预测模型实际使用24个原始特征，名单见outputs/tables/metrics.json。聚类标签、ABC和中文派生字段均不进入预测，避免将全样本结果回流至测试评估。

## 分母及不确定性

- 总体或筛选后离职标签占比：该子集中Exited之和／子集行数。
- ABC贡献：某岗位离职标签人数／全体237条离职标签。
- 岗位离职比例：某岗位离职标签人数／该岗位人数。
- Wilson区间：各组二项标签比例的95%区间，只反映该样本计算框架下的不确定性。
- Bootstrap区间：固定训练完成模型，对368条测试记录重采样1000次计算AP/AUC百分位区间，不包含重新训练的不确定性。
- 空筛选：人数0，比例与收入中位数显示“无样本”，不显示为零风险。

## 清洗及验证

未删除任何有效员工行；缺失和重复均为0。常量不进入模型；收入高值保留。模型预处理仅在训练折拟合。清洗和结果验证日志见outputs/tables/cleaning_audit.csv及docs/validation.json。
